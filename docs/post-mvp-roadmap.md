# Post-MVP Roadmap

## Phase 1 - Production Stabilization

- Live Stripe, Google, SMTP, Cloudinary, and cron monitoring.
- Webhook verification and alerting.
- Production database backups.
- Error monitoring/log drains beyond console diagnostics.
- Hotfix process and rollback notes.
- Better operational dashboards for failed refunds/transfers/emails.

## Phase 2 - Core UX Improvements

- Full reschedule flow with payment preservation.
- Session reminders 24h and 1h before the session.
- Therapist availability editor rather than fixed business-hour slot generation.
- Improved email templates and branding.
- Mobile/admin table polish.
- More visible Google/Stripe readiness guidance for therapists.

## Phase 3 - Business Growth Features

- Admin analytics.
- Advanced admin filters, search, and pagination.
- Financial reporting and exports.
- Therapist reviews.
- Therapist search filters.
- Client notifications and notification preferences.

## Phase 4 - Monetization Expansion

- Packages.
- Subscriptions.
- Promo codes.
- Advanced payout rules.
- Client credits as an explicit business feature if desired.
- Therapist plans.
